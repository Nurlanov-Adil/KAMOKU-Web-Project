# KAMOKU - Responsive Web Design

Assignment 3 for WEB Technologies.

## About the Project

KAMOKU is a fictional Japanese-inspired band website.  
The project demonstrates responsive web design using both custom CSS media queries and Bootstrap 5.

## Task 1 - Media Queries

The Members section was created using custom CSS Grid and mobile-first media queries.

- Mobile: 1 card per row
- Tablet: 2 cards per row
- Laptop: 3 cards per row

Breakpoints also change spacing and heading sizes.

## Task 2 - Bootstrap

The other sections use Bootstrap 5.3.

The project includes:

- Responsive Bootstrap navbar
- Bootstrap grid system
- Responsive cards
- Two-column About section
- Bootstrap utility classes
- Hidden content on mobile
- Bootstrap accordion
- Responsive footer

## Responsive Sizes

The website was tested at:

- 375px
- 768px
- 1280px

## Technologies

- HTML5
- CSS3
- Bootstrap 5.3
- CSS Grid
- Media Queries
